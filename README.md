# 🚌 SafeTrack Bus Booking System

A Java-based bus booking and tracking system with separate dashboards for admins and passengers.

## 🛠️ Tech Stack
- **Language:** Java
- **UI:** JavaFX
- **Database:** MySQL
- **IDE:** IntelliJ IDEA

## ✨ Features
### Admin
- Manage buses, routes, and schedules
- View all bookings and passengers
- Handle emergency alerts
- Dashboard with statistics

### Passenger
- Register and login
- Search and book bus tickets
- View booking history
- Emergency alert system

## 📁 Project Structure
```
src/com/safetrack/
├── controller/   → Business logic
├── dao/          → Database access
├── model/        → Data models
├── view/         → JavaFX UI screens
├── service/      → Services
└── util/         → Database & session utilities
```

## 🚀 How to Run
1. Clone the repository
2. Open in IntelliJ IDEA
3. Set up MySQL database
4. Run `Main.java`
